# components/city

The MRPII City control panel (FE-7..FE-47), opened at `/city` (FE-51). Rebuilt from the style prototype's variant A
(FE-35). The pure logic it draws from lives in `lib/city/`. Reads only the observer doors; decides nothing.

| File | Purpose |
| --- | --- |
| `CityView.tsx` | The page: live data, the 3D City and the screen layout (FE-38): wires the cards, toasts and pulse rings (FE-39: baseline = the backlog read when `caughtUp` turns true, reset on a scenario restart), and opens the classic panel's views, one card at a time (opening another, or the More menu, closes the open one): small panels (New order, Customers, Disruptions) and the More menu left of the camera strip; big views (Agent conversation, Disruption stories, Plan changes, Order story) in the 3D area between the agent rail and the strip; Run report as a dialog; the camera strip (zoom, rotate, view angle, Whole City) with the toasts stacked under it. URL params: `site`, `time`, `fps=1`, `customers=N` (preview houses for fps), `sel=` (preselect, for screenshots). |
| `hud.tsx` | Top bar (Site switcher, run controls ▶ / +1h / +1d, the live simulated clock (weekday and date, hour, the shift as a bar of hours, what is happening now: agents working, playing, shift over), ＋ New order, More menu, time of day, fps, AI switch), KPI strip (click filters the feed), agent rail, toasts. Run controls go through `lib/useSimDoors.ts`, shared with the classic `TopBar`. |
| `sidebar.tsx` | Right column: live activity feed (All / Events / Negotiations / Problems; click flies there), docks / lines / zones (click selects); order tracking bottom-left (a stopped order shows as stopped, never as progress). |
| `CityCanvas.tsx` | The 3D canvas with its failures handled: no WebGL, an error while drawing (reload button), a GPU context loss (auto restore or rebuild). |
| `camera.tsx` | Camera moves like the reference video (limits, glides to Sites; view angle 42° down by default, the user picks 28–62° with ⤒ / ⤓ in the camera strip, click the angle for the default, remembered in the browser) and the fps counter (draws and triangles of the whole frame, sun-shadow pass and bloom included). |
| `lighting.tsx` | Sun, sky and fog per time-of-day mode with a 3 s fade; lit windows glow with the night, street lamps (and people, vehicle lights) are on in Evening, Night and Midnight (FE-53); the shadow camera moves in whole texels so shadows do not crawl. Night bloom (FE-24, FE-49): mounted only while the lamps are on, strength follows their fade, only lights brighter than white halo; ACES tone mapping runs as its last step (the composer turns the renderer's off); no MSAA in the composer (cost ~20 % fps). |
| `contact.tsx` | Baked contact shadows (FE-24): each building declares its footprint (`<Footprint>` / `useFootprints`) beside its block; one merged mesh draws a soft dark fringe around all of them, reach about half the building's height, rebuilt only when footprints change (a new house). |
| `landscape.tsx` | Meadow, paved city, lawns (park middles: a low round lawn where agents stand to read events), roads, plants (oak, hedges, bushes, hydrangeas, grass clumps inside the fence, none outside for now; one instanced draw per model, low plants cast no shadow), grass tufts on the meadow (3×3 tiles round the camera, an outer ring at 40 % density when zoomed out; park and office lawns stay smooth), fences with gaps, the supplier entry gate; street lamps (model, instanced, arm over the nearest road) with a pool of light on the ground at night. |
| `square.tsx` | Town Square: the four-sided event board (newest event large, recent rows, ticker; NEW only for events arriving while watching), red steps, planters (their bushes are planted with the rest). |
| `offices.tsx` | The Sales, Planning, Purchasing and HR offices, each its own structure, with the agent's character. |
| `warehouse.tsx` | Warehouse Site: hall, dock doors with a truck (model) per pending delivery or shipment (hidden while that door's truck is driving), Warehouse and Inventory offices, zone racks, stock on model pallets, the yard lanes and the forklift charging bay. Positions from `lib/city/yard.ts`. |
| `movers.tsx` | Movement on real data only: `useMotion` (state), customer owners walking to Sales on an inquiry, negotiation messengers with envelope and bubble plus the dashed arc of each open negotiation (FE-23), event visitors (subscriber reads the event in a park, visits the publisher, goes home; no envelope), dock trucks and the three live forklifts carrying the event's goods (FE-52). |
| `forklift.tsx` | One forklift (grab3d model) with a load slot on its forks; the trips only move it. |
| `people.tsx` | People models: the standing pose baked once (rest pose, arms lowered) for agents, workers and owners (instanced crowds), and walkers / messengers playing the walk clip; everyone glows softly while the street lamps are on. |
| `models.tsx` | The model-pack models (ADR-004, FE-50) in `public/models/`: loading, shared parts, tinted copies, vehicle head- and taillights with a beam on the ground (`VehicleLights`), `ModelSlot` (a model that fails draws nothing, the City runs on). Rebuild them with `npm run models`. |
| `factory.tsx` | Factory Site: open hall, one line per work center with its light, HR's workers (man / woman model in a hard hat) at their lines, absent ones faded at HR. |
| `neighbourhood.tsx` | Customer houses (8 instanced designs), lit while an order is open, owners at the door (full model near the camera, light copy elsewhere), labels by zoom. |
| `marks.tsx` | The selection ring, the pulse rings of new actions (FE-39) and the supplier depot yard names (one depot per supplier is issue 03). |
| `DetailCard.tsx` | The selected element's detail card. |
| `kit.tsx` | Palette, shared materials, the City context and primitives: `DECAL` (depth offset for surfaces lying on others, against flicker), block, window facade, click target (`isClick` ignores drags), tag, sign, pin, an agent's person (Businessman model on a disc of the agent's colour). |
| `city.css` | Styles, all prefixed `city-`. |

Built so far: slices 2–8 of issue 06 (the City shell, the buildings, click-for-detail, the screen layout with run controls, movement along the roads, models: forklift, truck, pallet, street light, people, nature; contact shadows and night bloom; fps measured in slice 8, see the issue).
